BOSS PARTS & MODULAR SPECIALS
================================================================================
Bosses are procedurally assembled 112x112 pixel colossi built from 5 modular categories.
Severing a destructible part (Crown, Left Limb, Right Limb, Base) disables its special attacks.

1. Hull / Core Torso Styles (4 - Central Chassis)
   - CITADEL ("Citadel") -> Special: Fortress Siege Wall (HULL_CITADEL)
   - BOILER ("Juggernaut") -> Special: Pressure Vent Nova (HULL_BOILER)
   - DIAMOND ("Prism") -> Special: Refraction Matrix (HULL_DIAMOND)
   - RIBCAGE ("Automaton") -> Special: Heartcore Pulsar (HULL_RIBCAGE)

2. Crown / Head Styles (5 - Destructible Upper Segment)
   - HORNED (Horn Crown / Prefix: "Horned") -> Special: Horned Tempest (CROWN_HORNED)
   - SMOKESTACKS (Smokestacks / Prefix: "Foundry-Stack") -> Special: Cinder Rain Mortar (CROWN_SMOKESTACKS)
   - DOME (Prism Dome / Prefix: "Vaulted") -> Special: Orbital Prism Dome (CROWN_DOME)
   - PRONG_SPIRE (Rail Spire / Prefix: "Spire-Crowned") -> Special: Apex Rail Lance (CROWN_PRONG_SPIRE)
   - TURRET_CAP (Turret Cap / Prefix: "Bastion") -> Special: Auto-Cannon Sweep (CROWN_TURRET_CAP)

3. Limb / Wing Styles (5 - Independently Mounted on Left/Port & Right/Starboard; Destructible)
   - PAULDRON_ARM (Gauntlet Arm)
     * Port Special: Port Seismic Slam (LEFT_PAULDRON_ARM)
     * Starboard Special: Starboard Seismic Slam (RIGHT_PAULDRON_ARM)
   - CANNON_POD (Cannon Pod)
     * Port Special: Port Artillery Salvo (LEFT_CANNON_POD)
     * Starboard Special: Starboard Artillery Salvo (RIGHT_CANNON_POD)
   - CRYSTAL_WING (Crystal Wing)
     * Port Special: Port Featherblade (LEFT_CRYSTAL_WING)
     * Starboard Special: Starboard Featherblade (RIGHT_CRYSTAL_WING)
   - SHIELD_PLATE (Aegis Shield)
     * Port Special: Port Aegis Repulsor (LEFT_SHIELD_PLATE)
     * Starboard Special: Starboard Aegis Repulsor (RIGHT_SHIELD_PLATE)
   - CLAW_PINCER (Pincer Claw)
     * Port Special: Port Viper Pincer (LEFT_CLAW_PINCER)
     * Starboard Special: Starboard Viper Pincer (RIGHT_CLAW_PINCER)

4. Base / Locomotion Styles (4 - Destructible Undercarriage)
   - PILLAR_LEGS (Pillar Legs) -> Special: Titan Earthquake (BASE_PILLAR_LEGS)
   - TANK_TREADS (Tank Treads) -> Special: Juggernaut Overrun (BASE_TANK_TREADS)
   - THRUSTER_BELLS (Thrusters) -> Special: Afterburner Carpet Bomb (BASE_THRUSTER_BELLS)
   - SPIKE_KEEL (Spike Keel) -> Special: Meteor Keel Drop (BASE_SPIKE_KEEL)

5. Core Weak-Spot Slots & Shapes (5 Slots / 3 Geometry Shapes)
   - CHEST (Chest-Core) -> Special: Chest-Core Overdrive (CORE_RESONANCE_CHEST)
   - CROWN (Crown-Node) -> Special: Crown-Node Overload (CORE_RESONANCE_CROWN)
   - LEFT_POD (Port-Reactor) -> Special: Port-Reactor Surge (CORE_RESONANCE_LEFT_POD)
   - RIGHT_POD (Starboard-Reactor) -> Special: Starboard-Reactor Surge (CORE_RESONANCE_RIGHT_POD)
   - KEEL (Keel-Core) -> Special: Keel-Core Eruption (CORE_RESONANCE_KEEL)
   - Core Geometry Shapes: ORB, DIAMOND, SLIT (ringed by a segmented Gold protective collar bezel)

6. Synergy Combo Attacks (11 Part-Combination Specials)
   - Infernal Overpressure (COMBO_INFERNAL_OVERPRESSURE): Requires BOILER Hull + SMOKESTACKS Crown
   - Bastion Siege Barrage (COMBO_BASTION_SIEGE): Requires CITADEL Hull + TURRET_CAP Crown
   - Prismatic Annihilation (COMBO_PRISMATIC_ANNIHILATION): Requires DIAMOND Hull + PRONG_SPIRE Crown
   - Rend & Harvest (COMBO_REND_HARVEST): Requires RIBCAGE Hull + CLAW_PINCER Limb
   - Seraphim Crystal Dive (COMBO_SERAPHIM_DIVE): Requires CRYSTAL_WING Limb + THRUSTER_BELLS Base
   - Blitzkrieg Rolling Thunder (COMBO_BLITZKRIEG_THUNDER): Requires TANK_TREADS Base + CANNON_POD Limb
   - Cataclysm Piledriver (COMBO_CATACLYSM_PILEDRIVER): Requires HORNED Crown + SPIKE_KEEL Base
   - Phalanx Crusher (COMBO_PHALANX_CRUSHER): Requires PAULDRON_ARM Limb + SHIELD_PLATE Limb
   - Broadside Obliteration (COMBO_BROADSIDE_OBLITERATION): Requires Dual CANNON_POD Limbs
   - Solar Eclipse Featherstorm (COMBO_SOLAR_ECLIPSE): Requires Dual CRYSTAL_WING Limbs
